# Orchard

A premium, customizable Fabric client foundation for Minecraft 1.21.11.

## Current milestone

- Fabric client project targeting Java 21
- Orchard client entrypoint
- Right Shift menu keybind foundation
- Persistent theme configuration
- Optional Sodium compile-time compatibility
- GUI architecture ready for the next implementation pass

## Planned GUI sections

Sword, Mace, Cart, UHC, Spear, Crystal, Visuals, Silent, Settings, and Player Model.

The GUI is designed for desktop Minecraft and Android through PojavLauncher. Native Bedrock mobile is not supported by Java Fabric mods.
